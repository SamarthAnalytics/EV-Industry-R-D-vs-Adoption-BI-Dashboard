# EV-Industry-R-D-vs-Adoption-BI-Dashboard

Dashboard link: https://lookerstudio.google.com/u/0/reporting/f962250f-485c-4e08-928b-ec76e54a3d43/page/TN1dF

An AI-powered analytics dashboard exploring how automaker R&amp;D investments align with global EV adoption trends from 2018–2025.

Built with Python for preprocessing and trend modeling, and Looker Studio for visualization, the project quantifies the pace of innovation in the EV industry by comparing R&D intensity (% of revenue) against EV adoption growth.

Key Questions Answered:

Are automakers investing in R&D fast enough to match EV adoption?

Which companies lead in innovation efficiency (R&D-to-Revenue ratio)?

Does higher R&D intensity correlate with market growth and adoption success?

Insights:

Global EV adoption grew ~18% YoY, while R&D intensity only increased 9% YoY — revealing an innovation gap.

Rivian invests nearly 38% of its revenue into R&D, outperforming Toyota (3.4%) and GM (4.9%).

Companies with 6–8% R&D intensity achieved the highest revenue growth, suggesting diminishing returns beyond that range.

Tech Stack:

# AI & Analytics: Python (Pandas, NumPy, Scikit-learn)

# Visualization: Looker Studio (Google Data Studio)

# Data: Custom CSV datasets — EV share, R&D ratio, and automation levels

Highlights:

AI-assisted preprocessing for data normalization and outlier detection

Predictive modeling to forecast adoption vs. R&D trends to 2025

Interactive dashboard with filters for Quarter, Year, and Company
